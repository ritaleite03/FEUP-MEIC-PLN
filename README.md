## 📂 Projects Overview

Repository for **Processamento de Linguagem Natural (Natural Language Processing)** course projects at MEIC - FEUP.

| Project                            | Description                                                                                                                                                                                                                                             | Folder       |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| Traditional NLP Classification | Predict text classes using traditional ML classifiers (Naive Bayes, Logistic Regression, Random Forest, SVM, etc.). Includes data exploration, preprocessing, feature engineering (TF-IDF, embeddings), model training, evaluation, and error analysis. | `project_1/` |
| NLP with Transformers          | Fine-tune pre-trained Hugging Face transformer models for text classification. Includes tokenization, transformer fine-tuning, evaluation, optional domain adaptation (LoRA), and comparison with Project 1 results.                                    | `project_2/` |
