## Overview

This repository contains **two NLP projects** developed for the **Natural Language Processing (PLN) course, MEIC 2024/25** at the Faculty of Engineering, University of Porto.  

Both projects focus on **text classification**, with the first using traditional ML classifiers and the second leveraging **Hugging Face Transformers** for fine-tuning.

## Projects

### Project 1 – Traditional NLP Classification
- **Goal:** Predict text classes using traditional machine learning classifiers (Naive Bayes, Logistic Regression, Random Forest, SVM, etc.).  
- **Key Steps:** Data exploration, preprocessing, feature engineering (TF-IDF, embeddings), model training, evaluation, and error analysis.  
- **Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter.  
- [→ See Project 1 README](project_1/README.md)

### Project 2 – NLP with Transformers
- **Goal:** Fine-tune pre-trained Hugging Face transformer models for the same text classification task.  
- **Key Steps:** Data preprocessing, tokenization, transformer fine-tuning, evaluation, optional domain adaptation (LoRA), comparison with Project 1 results.  
- **Technologies:** Python, Hugging Face Transformers, PyTorch, Pandas, Jupyter, Matplotlib, Seaborn.  
- [→ See Project 2 README](project_2/README.md)
